# ENCY4AI：持续演进的人工智能百科全书与实用指南

[English / 主 README](README.md)

## 项目愿景

**ENCY4AI 最终希望成为人们面对 AI 信息爆炸时的知识基础设施：不必追逐每一个新消息，而是让每一次有价值的发现都成为长期知识积累的一部分。**

AI 的发展速度远超多数人理解、消化和实际尝试新技术的速度。我们不希望仅仅收藏更多新闻、论文和网页，而是把零散发现逐渐转化为有脉络、能理解、能应用、可以持续更新的知识体系。

ENCY4AI 采用 Wiki 与带语义的知识图谱，连接人工智能历史、基础理论、技术架构、模型、工具、智能体、实用指南、行业实践、人物机构以及未来发展。读者既可以像读书一样系统学习，也可以从任何一个词条、资料或问题出发，追溯技术来源、前置知识、演化、比较、应用和证据。

## 主要工作流（规划中）

- 随手收藏：提交有趣或有用的网页、论文、项目、教程，以及个人感悟、疑问、想法。
- 消化：提取来源支持的要点、背景、意义和未知问题；区分事实、作者观点、个人想法与 AI 推断。
- 串联：匹配已有知识，解释具体关系、相同与不同之处、前置知识、冲突证据和潜在应用。
- 尝试：在合适时提供可执行的小实验、学习路线、工具比较或实践指南；标注版本、时间成本和验证状态。
- 回顾：整理未读内容、待尝试项目和自上次阅读以来的重要变化，不必逐条补看旧新闻。

私人收藏与公共百科严格隔离。个人笔记和未审核提案默认不公开；只有授权且核实的内容才可纳入公共知识体系。
